## 📂 Featured Projects

### 🔹 [Flight Data Engineering Pipeline](https://github.com/Rider-04/flight-data-engineering-pipeline)
`MySQL` `Pentaho Spoon` `SQL` `Star Schema` `Power BI`

End-to-end ETL pipeline that turns **445K+ raw flight records into a 6,324-row analytics-ready dataset** (~98% volume reduction) in about 4–5 minutes. Includes a star-schema warehouse (`dim_airline`, `dim_airport`, `dim_month`, `dim_date`), reusable SQL views and 4 Power BI dashboards covering overview, airline performance, route analysis and delay analysis.

### 🔹 [Bank Loan Default Risk Analysis](https://github.com/Rider-04/bank-loan-default-risk-analysis)
`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn`

Preprocessing and feature-engineering workflow on a 55K-row, 122-column loan dataset: null analysis, outlier handling, type fixes and 10+ engineered features (income segments, credit ratios, EMI burden, loan affordability). Analysis surfaced higher default risk in low-income, unstable-employment and high-EMI segments.

### 🔹 Student Performance & Contest Analytics Pipeline
`MySQL` `SQL` `Data Modeling` `Power BI` `DAX`

Consolidated 10 contest leaderboards (UNION ALL) across 5+ datasets into a dimensional model with a contest fact table and student, contest and student-year dimensions. Uses stored functions, window functions (`DENSE_RANK`), min–max normalization and Power BI dashboards with 10+ KPI cards.

### 🔹 More ML Projects
- **[Insurance Incentive Prediction](https://github.com/Rider-04/Insurance_incentive_prediction)**: ML pipeline with a FastAPI backend, deployed on Render for real-time inference
- **Indian Cab & Auto Fare Prediction**: merged multiple ride-booking datasets (including a [synthetic fare dataset on Kaggle](https://www.kaggle.com/datasets/parthrider04/synthetic-fare-dataset)) and built a fare prediction model
